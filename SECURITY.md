# Security policy

Security reports should be submitted privately through the GitHub security advisory form for this repository. Include affected routes or module releases, reproduction steps, expected impact, and relevant logs with secrets removed.

Do not submit active credentials, access tokens, private keys, session cookies, or complete webhook URLs in an issue.

Reports about a registry module should include its module name and release identifier. Reviewers can quarantine a release while the report is investigated.

The registry scanner is a review aid. It does not sandbox modules and a passing result is not a guarantee of safety.
